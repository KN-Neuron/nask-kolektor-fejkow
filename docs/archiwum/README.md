# Archiwum dokumentacji

Dokumenty historyczne z etapu, w którym głównym silnikiem był `fejki` (tag `legacy-v1`): wiele kanałów z noisy-OR, opcjonalny model par
uczony, wyniki eksperymentów LEACE, dziennik decyzji i plan pracy. **Nie opisują obecnej metody.** Obowiązująca metoda to `embsim`:
jedno wyrażenie podobieństwa bez uczenia, patrz `../METODYKA.md`, `../14_WZOR_PODOBIENSTWA.md` i `../WYNIKI.md`.

Uwagi:
- `02_DANE.md` i część pozostałych plików opisują dane organizatora; zgodnie z zasadami zadania repozytorium musi pozostać prywatne,
  a te opisy usunąć przed ewentualnym upublicznieniem.
- Sprzeczność z obecnym stanem jest zamierzona i znana, np. `12_ZGODNOSC_Z_WYMAGANIAMI.md` mówi, że domyślny jest model par uczony
  (to dotyczy starego silnika; w `embsim` nic się nie uczy).
